## 🛠️ Technologies Used

- **HTML5:** Creates the structure of webpages.
- **CSS3:** Styles webpages with colors, fonts, spacing, and backgrounds.
- **CSS Grid:** Arranges content into responsive columns.
- **CSS Hover Effects:** Adds visual effects when users move the mouse over elements.

2. Save each website's code in an `.html` file.
3. Open the file in Visual Studio Code or another code editor.
4. Run the HTML file in a web browser.
5. Explore the website sections using the navigation links.
